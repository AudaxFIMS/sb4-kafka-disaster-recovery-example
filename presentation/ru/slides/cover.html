Kafka DR Starter

Переключение между кластерами Kafka без потерь, без дублей и без кода отказоустойчивости в приложении

Spring Boot 4 · Spring Cloud Stream 5 · spring-kafka 4 · Java 17+

Стартер для Spring Boot, который делает приложение на Spring Cloud Stream устойчивым к падению кластера Kafka. Ключевая идея: приложение пишет обычные обработчики, а переключение кластеров, дедупликация и восстановление позиции чтения задаются конфигурацией.
