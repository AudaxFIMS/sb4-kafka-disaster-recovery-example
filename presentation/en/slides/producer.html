The main lesson of the development. Every mistake towards "the message is at fault" is a loss for a bridge — the record goes to the DLQ. Every mistake towards "the cluster is at fault" is a needless failover of the whole group, and flapping. So: the message is at fault only for provable properties of the record; the cluster is broken only when it is unreachable or a retriable Kafka error outlasted the retries; everything else is held. Sends are always synchronous: the starter sets sync: true itself. The active-only rule came from a live run: detouring to a standby left records unread.
