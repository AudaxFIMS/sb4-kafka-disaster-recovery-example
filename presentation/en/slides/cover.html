Spring Boot starter · Kafka disaster recovery

Kafka DR Starter

Switching between Kafka clusters with no loss, no duplicates and no failover code in the application

Spring Boot 4 · Spring Cloud Stream 5 · spring-kafka 4 · Java 17+

A Spring Boot starter that makes a Spring Cloud Stream application resilient to the loss of a Kafka cluster. The key idea: the application writes ordinary handlers, while cluster switching, deduplication and restoring the read position are configuration.
