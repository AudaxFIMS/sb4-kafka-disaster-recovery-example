# Presentation / Презентация

Kafka DR Starter overview deck — 14 slides: the problem, how the starter solves it, cluster groups and
bridges, verification, pros and cons, when to use it. Each slide carries speaker notes.

| File | What |
|---|---|
| `kafka-dr-starter-en.html` | English deck, self-contained: open in a browser |
| `kafka-dr-starter-ru.html` | Russian deck, self-contained: open in a browser |
| `en/`, `ru/` | Sources: `deck.json` (order, sections, fonts) and one `slides/<id>.html` per slide |

In the HTML files: **N** toggles speaker notes; **Ctrl/Cmd+P** prints one slide per page (save as PDF).
Fonts (IBM Plex Sans, JetBrains Mono) load from Google Fonts; offline, a basic face stands in.

Обзорная презентация Kafka DR Starter, 14 слайдов, с заметками докладчика. Откройте
`kafka-dr-starter-ru.html` или `kafka-dr-starter-en.html` в браузере: **N** показывает заметки,
**Ctrl/Cmd+P** печатает по слайду на страницу (сохранение в PDF). Исходники слайдов — в `ru/` и `en/`.
